# CareerGraph Studio

Build the complete CAREERGRAPH frontend UI/UX exactly as requested. Frontend only: React + TypeScript + Tailwind + shadcn/ui + Lucide + React Router. Do not add backend, database, auth providers, AI/RAG APIs, blockchain, external APIs, integrations, or real business logic. Use local realistic mock data, separated types/data/services with mock service functions consumed by UI. Deliver premium strict-monochrome editorial career-intelligence design, responsive/accessibly navigable. Build all specified public, student, admin, faculty, and senior pages/features in the stated order. Ensure every page is visibly complete and routes, interactions, loading/empty/error/success/validation and button states are represented in frontend.

This project was built with [Lovable](https://lovable.dev).
